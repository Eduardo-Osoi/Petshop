PETSHOP

pagina web tienda de mascotas en linea El desarrollo de un sistema gestor para una tienda en linea (PETSHOP) con carrito de compras . 
El odjetivo es diseñar e implementar una plataforma donde los usuarios puedan comprar productos para mascotas, administrar pedidos, realizar pagos y gestionar inventarios 
Herramientas y tecnologías que utiliza

Las tecnologías que menciona son:

HTML: para la estructura de las páginas web. CSS: para el diseño y la apariencia. 
JavaScript: para la interactividad del sitio. PHP: para el desarrollo del backend (lógica del sistema y conexión con la base de datos). 
MySQL: gestor de base de datos principal. PostgreSQL y MongoDB: se presentan como alternativas de base de datos.

Herramientas y tecnologías como:

XAMPP (Apache + PHP + MySQL) para ejecutar el proyecto en un servidor local. phpMyAdmin para administrar la base de datos.
